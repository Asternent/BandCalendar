# BandCalendar · 腕上日曆

為中國版 **Xiaomi Band 10 Pro＋Android** 製作的獨立日曆。
全球節日與中國大陸放假／補班分開顯示，不會將其他國家的假期當成大陸放假日。
目前版本 **0.2.0**，試用版；可與 BandMarkets・腕上股市同時安裝。

[下載 0.2.0 安裝包](https://github.com/Asternent/BandCalendar/releases/tag/v0.2.0) · [授權條款](LICENSE) · [更新記錄](CHANGELOG.md)

## 功能

- 雙端原生月曆、前後月份、回到今天、星期與農曆、點日期查看節日詳情。
- 內建 **2025–2028 年**、**249 個國家／地區**的國家層級公眾假期（另列中國大陸官方安排），以及常見傳統節日、國際紀念日、民俗節日與二十四節氣。
- 手機可依地區中文名稱或代碼（如 US、JP）搜尋，查看全球或指定地區的公眾假期。常見節日附中文名稱，其餘保留資料來源原名。
- **「休／班」僅表示中國大陸官方放假調休／補班**，本版收錄已核對的 2025、2026 年安排。一般週末不是法定假日標記，不代表個人的工作班表。
- 2027、2028 年仍可看月曆、農曆及節日，但顯示「大陸調休安排未收錄」，**不推算放假或補班**。
- 手機採用原生 Android Views，跟隨系統深淺色；手環採用 Vela 原生元件與深色 Material 風格。
- **日曆資料完全離線內建**，手環不需要先同步就能使用。手機只同步國別範圍、週一／週日起始、國際紀念日與節氣顯示偏好。
- 同步以手環儲存成功後的確認訊息為準；失敗保留原設定。手環可臨時切換全球／大陸瀏覽範圍，不會變更手機的偏好。

這並非世界上所有地方、民族、宗教或學校假期的全集。國別資料使用無 subdivision 的公眾假期，可能包括觀察／補休日；未來尤其宗教節日日期可能是預估，會隨官方公告調整。請以當地官方最新資料規劃重要行程。資料不會自動更新；新增年度安排需更新安裝包。

## 0.2.0：操作邏輯與介面重整

- **先選取，再查看**：點其他日期先更新上方常駐位置的精簡摘要；再點已選日期，或點摘要，才開啟完整詳情。鄰月日期加上「n月」提示，單點會切換到該月份，不會誤認為本月。
- **更容易換月**：點月份標題開啟年份／月份快速選擇，選月份立即前往，返回取消不改日期。左右換月保留原本想看的幾號；如 1/31 → 2/28 → 3/31，閏年自動處理 2/29。
- **詳情逐日瀏覽**：加入前一天／今天／後一天；換日期會回到節日第 1 頁。節日資料仍每頁最多 8 組，頁碼與逐日導航分開，不混淆。返回顯示正在查看的日期，跨月時回到正確月份。
- **一致的返回**：說明返回選單，選單／跳月／詳情返回月曆，只有月曆根頁才離開 App。資料邊界的按鈕變暗並提供提示，不悄悄失效。
- **獨立選單**：顯示範圍、手機同步、資料來源移出首頁。可暫時查看全球／大陸，並有明確的「恢復手機設定」；臨時範圍不寫回手機，也不會被後續背景同步突然改掉。
- **同步不打斷閱讀**：收到手機偏好後先儲存並確認，待返回月曆才套用；不會把正在讀的詳情、跳月年份或選單重設。重複同步點擊會合併，失敗或逾時後可重試。
- **更清楚的畫面層次**：月份與摘要置頂、六行日期格、次要說明與本月假期卡片置後。以 336×480 螢幕、456 高度模型檢查，標題／摘要／完整六行日期格共 450 設計像素；其他比例可捲動。主要操作目標至少 44×44 設計像素。沿用 Material 深色與紅／綠／藍日期，不改掉假期含義。
- 保留 0.1.4 的固定 42 格、輕量摘要及延後詳情載入。新增閏年、31 日換月、返回堆疊、同步與操作併發測試。**主機測試不等同手環實機驗證**。

## 0.1.4：手環流暢度再優化

- 換月、國別篩選與週起始變更皆保留原有 6 行、42 格，僅更新不同欄位；不重建整個日期陣列。每格移除一層容器，日期格的模板節點由 210 降至 168（減少 20%）。
- 月曆與選取摘要採輕量預覽，啟動及換月不解碼全球節日詳情；點進詳情才建立完整資料。全球節日、農曆、紅／綠／藍數字、休／班與假期天數沒有刪減。
- 閱讀詳情、免責頁或熄屏時不更新隱藏月曆；返回再補上最新月份／設定。詳情翻頁重用列物件，最多 8 組，翻頁後等待佈局完成再回頂，過期回呼不干擾新頁面。
- 手環通訊移至頁面就緒後初始化，離線月曆先呈現。資料快取改為固定上限的環形索引；冷月份只建立 42 個日期物件，一次 UTC 轉換。
- 新增啟動、連翻 48 月、隱藏同步、跨午夜、翻頁返回與節點保留測試。效能報告比較**上一版 0.1.3**，僅為主機模型測量，不宣稱手環 FPS 或實際觸控延遲。
- 新 RPK 可與原手機同步器 0.1.3 通訊；0.1.4 APK 僅更新版本及內附的新 RPK。此次未操作或自動更新使用者手機。

## 0.1.3：一眼看懂哪天休、連休幾天

- **日期數字分色＋淡色背景**：紅色為中國大陸官方放假調休日，綠色為補班日，藍色為一般週末（按週休二日參考），普通平日中性色。星期六／日遇到補班時優先顯示綠色，不再因為是週末而顯示成休息日。
- 今天以標記／外框提示，選取以紫色底提示，均不覆蓋日期原本的放假／補班顏色。全球節日與紫色節日簡稱不會把普通平日染成紅色。
- 月曆上方顯示本月官方假期的起訖及天數；點日期可看「連休 N 天」和完整日期範圍，手機詳情另列假期第幾天。跨月假期顯示完整起訖及完整天數，不在月底截斷。
- 天數只計資料中**連續的官方放假調休日**，不額外加上請假或未列入的週末；不代表所有人的個別排班。2027–2028 年未收錄官方安排，保持中性數字並提示未收錄，不推算放假、週末休息或補班顏色。
- 新增逐日假期類別／連休區間比對：雙端 1,461 個日期與 48 份月份摘要一致。

## 效能驗證

比較上一版的可重現測試：`node tools/benchmark.cjs`。基準來源在 `test/fixtures/perf-014/`；結果列於 `reports/performance-model.json` 與交付的效能檢查報告。測試排除實機 Vela 繪製、藍牙、儲存和硬體觸控耗時，不可將模型加速倍數當成實機加速倍數。

## 安裝與使用

1. Android 8 以上安裝 **BandCalendar-Sync-0.2.0.apk**。手機上先前安裝的 0.1.0 可直接覆蓋升級，偏好會保留。
2. 用已設定好的 AstroBox 或相容手環安裝工具安裝 **BandCalendar-Band-0.2.0.rpk**。手機「手環 → 安裝手環端程式（RPK）」內含同一份檔案。
3. 在手環開啟 **腕上日曆**，即可離線瀏覽。單點日期選取，再點同日或上方摘要看詳情；點月份可跳月；「選單」調整範圍、同步與閱讀聲明。一般返回逐層回到月曆。
4. 手機「月曆」點上方月份可跳至日期，或按左右箭頭換月。「節日」可看整月列表，點日期／查看按鈕閱讀全部適用地區。
5. 如要同步偏好，先退出 AstroBox，讓**中國版小米運動健康**連上手環。在手機日曆選擇範圍與偏好，點「連接並同步設定」；首次另需完成「授權手環通訊」。手環端日曆也需保持開啟。
6. 手機顯示「手環已確認收到並儲存設定」才代表同步成功。僅顯示已傳送並不等同已保存。手機同步器需保持運行，手環才能主動請求同步。

兩端包名皆為 `com.bandcalendar.sync`，使用同一組本專案簽章；與股市程式的包名及簽章分開。小米運動健康或韌體的第三方接入條件可能限制通訊，這不影響離線月曆與節日瀏覽。不要為了同步授予不相關的健康或通知權限。

## 建置

需要 Node.js 20+、JDK 17、PowerShell 7、OpenSSL（如 Git for Windows 內附版本）、Android SDK platform 34+ / build-tools 34+。

```powershell
./tools/prepare-sdk.ps1
./tools/create-signing.ps1
npm --prefix band ci
npm --prefix band run release
Copy-Item band/dist/com.bandcalendar.sync.release.0.2.0.rpk android/app/src/main/assets/band.rpk
./tools/build-android.ps1
./tools/test.ps1
```

產物位於 `band/dist/` 及 `dist/`。新建簽章僅限首次本地建置；升級現有安裝必須沿用原私鑰。`signing/` 與 `band/sign/` 必須保密，不包含在原始碼 ZIP 中。

離線資料可重建：安裝 Python 3.10+、`pip install -r tools/requirements-data.txt`，再執行 `python tools/generate-data.py`。固定版本的 holidays 套件、原始天文台 CSV／文字表、產生規則與結果一併提供。手環資料以名稱字典與逐日壓縮字串儲存，僅解析所開啟日期，避免一次建立數萬個節日物件。
